# 05 — Data Science Skills Mastery Lab

## Goal
Provide a compute-friendly skills laboratory inspired by the professor's
prompt to demonstrate data-science skills using appropriate datasets and
CRISP-DM.

## Important note
The professor's original prompt references external skill packages
(`agent-ml-skills` and `data-analytics-skills`). This student implementation
provides a local, auditable skills catalog and representative demonstrations.
It does not claim to reproduce proprietary/external skill definitions that
are not included in the prompt text.

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

The dashboard demonstrates representative skills across:
- data understanding
- data cleaning
- statistics
- visualization
- supervised learning
- unsupervised learning
- dimensionality reduction
- anomaly detection
- association rules
- model evaluation
- deployment concepts
