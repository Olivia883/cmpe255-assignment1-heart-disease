# 03 — Customer Segmentation Clustering

## Goal
Reproduce the clustering experiment using a popular Kaggle customer
dataset and CRISP-DM.

## Input
Place `Mall_Customers.csv` in `data/`.

Expected columns:
- CustomerID
- Gender
- Age
- Annual Income (k$)
- Spending Score (1-100)

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```
